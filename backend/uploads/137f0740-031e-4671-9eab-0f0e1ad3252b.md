1. 更新 `apt` 列表
   ```bash
   sudo apt update
   ```
2. 安装 `dvwa`
   ```bash
   sudo apt install dvwa
   ```
   按 `y` 确认安装
3. 启动 `dvwa`
   ```bash
   sudo dvwa-start
   ```
4. `Linux` 会自动打开 `dvwa` 靶场，默认的用户名是 `admin`，密码是 `password`
5. 点击 `Create/Reset Database` 按钮，创建或重置数据库
   ![创建数据库](/img/Linux中一条指令搭建dvwa靶场/创建数据库.png)
6. 等待数据库创建完成，重新登录 `dvwa` 靶场
   ![最终效果](/img/Linux中一条指令搭建dvwa靶场/最终效果.png)
7. 如需退出，执行
   ```bash
   sudo dvwa-stop
   ```
