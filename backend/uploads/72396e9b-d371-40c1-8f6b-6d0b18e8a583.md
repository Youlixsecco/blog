# 一、安装 Node.js 和 Git
1. 安装 Node.js
- 更新软件源列表
  ```bash
  sudo apt update
  ```
- 安装 Node.js 和 npm
  ```bash
  sudo apt install nodejs npm -y
  ```
- 安装验证
  ```bash
  node -v
  npm -v
  ```
2. 安装 Git
- 安装 Git
  ```bash
  sudo apt install git -y
  ```
- 安装验证
  ```bash
  git --version
  ```
# 二、安装 Hexo
1. 安装 Hexo
- 安装 Hexo
  ```bash
  sudo npm install -g hexo-cli
  ```
- 安装验证
  ```bash
  hexo -v
  ```
# 三、博客项目创建
1. 创建博客项目, 并进入项目目录,这里以 blog 为例
   ```bash
   mkdir blog
   cd blog
   ```
2. 初始化 Hexo 项目
   ```bash
   hexo init .
   npm install
   ```
3. 项目验证
   ```bash
   hexo generate
   hexo server
   ```
4. 访问 [http://localhost:4000](http://localhost:4000) 即可查看初步搭建好的博客
# 四、博客项目配置
1. 进入配置文件
   ```bash
   vim _config.yml
   ```
2. 站点基本信息设置
   ```yaml
   title: 我的技术博客          # 博客标题
   subtitle: 记录学习与成长      # 副标题（部分主题显示）
   description: 一个 Hexo 博客  # 博客描述（用于 SEO）
   keywords: Hexo, 博客, 技术   # 关键词（用于 SEO）
   author: 你的名字             # 作者名，会显示在页脚等位置
   language: zh-CN             # 语言，中文填 zh-CN
   timezone: Asia/Shanghai     # 时区,为空时默认使用系统时区
   ```
3. 主题设置, 这里以 Butterfly 为例
- 安装 Butterfly 主题
  ```bash
  git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly
  npm install hexo-renderer-pug hexo-renderer-stylus --save
  ```
- 配置主题
  ```yaml
  theme: butterfly
  ```
4. 关闭 _config.yml 文件, 并保存
5. 建立独立主题配置文件, 之后可在 _config.butterfly.yml 中配置主题相关参数
   ```bash
   cp themes/butterfly/_config.yml _config.butterfly.yml
   ```
6. 本地预览 Butterfly 主题博客
   ```bash
   hexo clean
   hexo generate
   hexo server
   ```
7. 访问 [http://localhost:4000](http://localhost:4000) 即可查看 Butterfly 主题博客
# 五、博客部署到 GitHubPages
1. 创建 GitHub 仓库
- 登录 GitHub 并创建一个新的仓库, 仓库名称为 你的用户名.github.io
- 仓库设置为公开
2. 配置 _config.yml 文件, 此处路径为 blog/_config.yml
- 设置网址
  ```yaml
  url: https://你的用户名.github.io/你的用户名.github.io
  ```
- 部署设置
  ```yaml
  deploy:
    type: git
    repo: git@github.com:你的用户名/你的用户名.github.io.git
    branch: main
  ```
3. 配置 SSH 密钥
- 生成 SSH 密钥
  ```bash
  ssh-keygen -t ed25519 -C "你的邮箱"
  ```
  后续直接回车即可
- 查询并复制公钥
  ```bash
  cat ~/.ssh/id_ed25519.pub
  ```
- 登录 GitHub 并添加公钥到 SSH 密钥对
- 点击设置 -> SSH 密钥对
- 点击添加密钥对
- 输入密钥对名称, 例如 blog
- 粘贴公钥内容
- 点击添加密钥对
- 测试 SSH 连接
  ```bash
  ssh -T git@github.com
  ```
  如果返回 "Hello, 你的用户名! You've successfully authenticated, but GitHub does not provide shell access." 则表示配置成功
4. 安装 Hexo 插件
   ```
   npm install hexo-deployer-git --save-dev
   ```
5. 部署博客
   ```bash
   hexo clean
   hexo generate
   hexo deploy
   ```
   等待 5-10 分钟即可在 [https://你的用户名.github.io/你的用户名.github.io](https://你的用户名.github.io/你的用户名.github.io) 查看部署好的博客
