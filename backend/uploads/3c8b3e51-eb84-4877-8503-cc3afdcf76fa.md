#### 转移 Linux 上的 blog 项目到 Windows
1. 初始化 Git
   ```bash
   git init
   ```
2. 添加远程仓库
   ```bash
   git remote add origin git@github.com:用户名/仓库名.git
   ```
3. 添加文件
   ```bash
   git add .
   ```
4. 提交文件
   ```bash
   git commit -m "初始提交"
   ```
5. 推送文件到远程仓库
   ```bash
   git push -u origin 主分支名
   ```
6. 在 Windows 上拉取备份的 blog 项目
   ```bash
   git clone git@github.com:用户名/仓库名.git
   ```
#### 配置 Windows 上的 blog 项目
1. 安装 [Node.js](https://nodejs.org/en/download)
2. 验证 Node.js 安装
   ```bash
   node -v
   npm -v
   ```
3. 安装 hexo
   ```bash
   npm install hexo-cli -g
   ```
4. 验证 hexo 安装
   ```bash
   hexo -v
   ```
5. 拉取 blog 主题，这里是 butterfly 主题
   ```bash
   git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly
   npm install hexo-renderer-pug hexo-renderer-stylus --save
   ```
6. 安装依赖
   ```bash
   npm install
   ```
7. 预览迁移后的 blog 项目
   ```bash
   hexo clean
   hexo generate
   hexo server
   ```
   访问 [http://localhost:4000](http://localhost:4000) 即可查看迁移后的 blog 项目
